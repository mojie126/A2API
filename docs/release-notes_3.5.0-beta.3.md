# Agent2API 3.5.0-beta.3 资产草稿（fork）

基于官方 3.5.0-beta.3（`cd0411bf`），协议库对齐 `v3.5.0-beta.2`；以下为 fork 增量改动，草稿正文由此文件自动生成，同版本的多次构建在本文件整合或追加。官方 beta.2 与 beta.3 的跟进与取舍见 `官方beta跟进清单_2026-11-19.md`。

## 核心更新

1. 新增：统一错误处理设置，按限流、额度耗尽、登录失效、连接异常分别配置重发、换号、冷却与失败保护。
2. 新增：运行容量管理，可自动或手动设置对话、登录、后台任务与图片任务的并发与排队上限。
3. 新增：系统提示词规则，按提供商、客户端与模型匹配，替换、追加或透传可预览命中结果。
4. 新增：账号列表按需分页与实时状态推送，减少重复读取与整页刷新。
5. 新增：插件批量安装、更新、启用、停用与卸载，展示逐项进度与结果；本机客户端启动入口。
6. 新增：网页工具调用模拟，为声明支持的两家模型补工具声明。
7. 新增：客户端识别供应商归属规则与默认归属客户端，请求日志按路由供应商改写归属。
8. 新增：models.dev 模型身份绑定与代理选择，能力值按用户覆盖、目录声明、models.dev 补齐的优先级合成。
9. 新增：模型管理可手动设置各提供商模型的思考档位，手动值优先于上游声明与 models.dev。
10. 新增：模型独立路由与自定义路由组支持组内并发设置，默认关闭，启用后按平均分配限制组内总并发。
11. 新增：ZCode 账号内建 WARP 出口池，默认开启；账号代理可引用 WARP 设备，请求日志展示出口方式。
12. 新增：网络代理页新增「代理列表 / WARP 设备」分页，展示出口 IP、端口、流量与最近使用时间。
13. 新增：商汤日日新支持手机号验证码登录与官网滑块验证，凭据自动续期。
14. 新增：调试模式支持三档采集内存预算，流式正文按头尾截断，调试数据采用有界异步批量写入。
15. 优化：ZCode 与 zcode-intl 改为直连优先，直连出口被占用或遇 429 时才使用出口池。
16. 优化：提供商插件保留原生安装与运行，不强制转为独立 WASM 包；插件更新与下载在官网通道之外保留 GitHub Releases 兜底。
17. 修复：图片兼容参与校验与保存校验对齐同一判据，视觉调用改用目标模型的账号池与路由 profile。
18. 修复：特殊请求路由的压缩上下文、图片兼容与标题生成规则保存后立即落库，修复旧配置回退与修订号冲突。
19. 修复：开启调试模式后打开已完成请求的详情会一闪而过，预览对话解析 Anthropic thinking 内容块异常。
20. 修复：ZCode 等内置提供商轮询档账号遇 429 时先换出口重试，不再直接冷却账号。
21. 修复：长时间运行后云同步包持续变大，限额台账移出同步范围并增加 30 天保留期修剪。
22. 修复：组内并发设置被容量准入绕开，准入与全忙判定改读组内分配结果。
23. 修复：WorkBuddy 凭据按 realm / region / edition 识别地区，余额列不再把 SOLO 并发数当成积分。
24. 允许彻底关闭更新检查：两个通道都关时软件与插件都不再发起网络请求，手动检查提示已关闭，强制更新不受影响。

## 其他更新

1. 新增：脚本插件 Bun 运行时一键清理；主面板注册百度搭子官方图标。

6. 优化：自动维护页模型目录更新的代理列与账号页统一口径。
7. 优化：请求日志模型列在模型名下方显示请求协议（Chat Completions / Responses / Anthropic / Images）。
8. 优化：长期 Cookie 类账号刷新只更新进程内令牌时不再误报凭据未更新。
9. 优化：报表 Top 账号悬停提示支持长标识换行，气泡最大宽度放宽。
10. 优化：弹窗遮罩去掉全屏背景模糊，入场出场改用轻量过渡；弹窗打开期间暂停后台轮询，低配设备自动关闭过渡。

12. 更新：数据库 schema 升至 v33，本地协议列、出口列与官方用量诊断列合并。
13. 更新：面板补充 deepaicode 与 codar 提供商图标，六语文案与前端产物同步重建。
14. 更新：工作流全部仅 `workflow_dispatch` 手动触发；发布说明按当前版本动态取用。
