# Agent2API 3.5.0-beta.3 资产草稿（fork）

基于官方 3.5.0-beta.1（`aba58858`），协议库对齐 `v3.5.0-beta.2`；以下为 fork 增量改动，草稿正文由此文件自动生成，同版本的多次构建在本文件整合或追加。官方 beta.2 与 beta.3 的合并进度见 `官方beta跟进清单_2026-11-19.md`。

## 核心更新

1. 新增：客户端识别供应商归属规则与默认归属客户端，请求日志按路由供应商改写归属。
2. 新增：models.dev 模型身份绑定与代理选择，能力值按用户覆盖、目录声明、models.dev 补齐的优先级合成。
3. 新增：模型管理可手动设置各提供商模型的思考档位，手动值优先于上游声明与 models.dev。
4. 新增：模型独立路由与自定义路由组支持组内并发设置，默认关闭，启用后按平均分配限制组内总并发。
5. 新增：ZCode 账号内建 WARP 出口池，默认开启；账号代理可引用 WARP 设备，请求日志展示出口方式。
6. 新增：网络代理页新增「代理列表 / WARP 设备」分页，展示出口 IP、端口、流量与最近使用时间。
7. 新增：商汤日日新支持手机号验证码登录与官网滑块验证，凭据自动续期。
8. 新增：调试模式支持三档采集内存预算，流式正文按头尾截断，调试数据采用有界异步批量写入。
9. 优化：ZCode 与 zcode-intl 改为直连优先，直连出口被占用或遇 429 时才使用出口池。
10. 修复：图片兼容参与校验与保存校验对齐同一判据，视觉调用改用目标模型的账号池与路由 profile。
11. 修复：特殊请求路由的压缩上下文、图片兼容与标题生成规则保存后立即落库，修复旧配置回退与修订号冲突。
12. 修复：开启调试模式后打开已完成请求的详情会一闪而过，预览对话解析 Anthropic thinking 内容块异常。
13. 修复：ZCode 等内置提供商轮询档账号遇 429 时先换出口重试，不再直接冷却账号。
14. 修复：长时间运行后云同步包持续变大，限额台账移出同步范围并增加 30 天保留期修剪。
15. 允许彻底关闭更新检查：两个通道都关时软件与插件都不再发起网络请求，手动检查提示已关闭，强制更新不受影响。

## 其他更新

1. 新增：脚本插件 Bun 运行时一键清理；主面板注册百度搭子官方图标。
2. 新增：动态登录指引中的链接可点击，面板内点击外链转交系统浏览器打开。
3. 优化：账号页代理列按配置、代理池与 WARP 设备版本重绘，后台刷新不打断展开中的下拉。
4. 优化：自动维护页模型目录更新的代理列与账号页统一口径。
5. 优化：请求日志模型列在模型名下方显示请求协议（Chat Completions / Responses / Anthropic / Images）。
6. 优化：长期 Cookie 类账号刷新只更新进程内令牌时不再误报凭据未更新。
7. 优化：报表 Top 账号悬停提示支持长标识换行，气泡最大宽度放宽。
8. 优化：tauri-build 升级到 2.7.4，适配 cargo 1.100 构建目录两级布局。
9. 更新：面板补充 deepaicode 与 codar 提供商图标，六语文案与前端产物同步重建。
10. 更新：工作流全部仅 `workflow_dispatch` 手动触发；发布说明按当前版本动态取用。
11. 版本：3.5.0-beta.1 → 3.5.0-beta.3
