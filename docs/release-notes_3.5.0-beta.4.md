# Agent2API 3.5.0-beta.4 资产草稿（fork）

基于官方 3.5.0-beta.4（`a781711a`），协议库对齐 `v3.5.0-beta.2`；官方发布说明见 <https://github.com/aimod-cc/Agent2API/releases/tag/v3.5.0-beta.4>，官方改动不在本文件重复列出。本文件只列 fork 相对官方版本的增量改动，同版本的多次构建在本文件整合或追加。

## 核心更新

1. 优化：ZCode 客户端版本号在签到触发时按官网更新日志探测并对齐最新版本，上游抬高活动门槛时无需手动改设置。
2. 新增：插件商店与插件更新切换到 fork 的插件索引仓库与 GitHub Releases 直连，不再依赖官网目录。
3. 修复：辅助识图规则保存时映射别名目标被误判「已不在提供商目录中」；识图上下文不再按条数与字节截断，由识图模型自身上下文决定；识图与整体接管分发不再执行会话图片压缩，原图直转视觉模型。
4. 新增：模型路由的组内并发支持无限并发账号，自动总数取有限并发账号上限之和，有限账号按自身上限分配、无限账号保持不限。
5. 修复：模型管理按倍率排序对 `0.2x` 后缀形态失效的问题，排序与显示统一解析两种倍率形态。
6. 新增：模型测试的测试节点支持选择 WARP 设备，结果标签带出口 IP。
7. 新增：面板验证码令牌池自动补货，上游要求验证码且库存为空时自动完成无痕验证并入池，免码期不铸造。
8. 修复：登录轮询与回调换码绑定登录弹窗选定的代理或 WARP 设备，不再静默回落直连。
9. 优化：模型路由改为自动参与，新添加账号带来的提供商无需手动加入，移除「参与方式」选择器。
10. 修复：删除账号同步清理路由配置中的账号与提供商引用，重新添加同一凭据不再复用旧位置或被旧排除项挡住。

## 其他更新

1. 修复：旧版全局路由名单自动纳入新增提供商，新增提供商不再被旧名单静默排除。
2. 优化：添加账号页来源筛选拆分为原生插件、Wasm 插件与 Magpie 插件；插件登录指引恢复链接点击；辅助识图规则弹窗布局调整。
3. 优化：WARP 设备出口槽位重启后自动接回，更新检查等待设备就绪。
4. 优化：小浣熊移除刷新令牌入口，粘贴登录态只需访问令牌。
5. 优化：组头「可用合计」按当前筛选后的成员计算。
6. 修复：无需续期的账号手动刷新不再误报「未接入续期」；配置更新重建全部派生快照，修复保存配置后再次保存撞修订号。
7. 修复：添加账号恢复 AutoClaw 国际版网页登录入口，Google 登录被上游拒绝时给出明确指引。
8. 版本：3.5.0-beta.3 → 3.5.0-beta.4
