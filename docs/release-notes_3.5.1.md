# Agent2API 3.5.1 资产草稿（fork）

基于官方 3.5.1（`33f5e797`），协议库对齐 `v3.5.0-beta.2`；官方发布说明见 <https://github.com/aimod-cc/Agent2API/releases/tag/v3.5.1>，官方改动不在本文件重复列出。本文件只列 fork 相对官方版本的增量改动，同版本的多次构建在本文件整合。

## 新增

1. 新增：插件商店与插件更新切换到 fork 的插件索引仓库与 GitHub Releases 直连，不再依赖官网目录。
2. 新增：模型路由的组内并发支持无限并发账号，自动总数取有限并发账号上限之和，有限账号按自身上限分配、无限账号保持不限。
3. 新增：模型测试的测试节点支持选择 WARP 设备，结果标签带出口 IP。
4. 新增：面板验证码令牌池自动补货，上游要求验证码且库存为空时自动完成无痕验证并入池，免码期不铸造。
5. 新增：Codex 订阅接入 `gpt-image-2` 图片生成与参考图编辑，支持尺寸、质量、背景与多参考图，图片额度与文字对话独立冷却互不连坐。

## 修复

1. 修复：辅助识图规则保存时映射别名目标被误判「已不在提供商目录中」；识图上下文不再按条数与字节截断；识图与整体接管分发不再压缩图片，原图直转视觉模型。
2. 修复：模型管理按倍率排序对 `0.2x` 后缀形态失效。
3. 修复：登录轮询与回调换码绑定登录弹窗选定的代理或 WARP 设备，不再静默回落直连；账号页「连接数」列在分页详情未加载时照常显示。
4. 修复：删除账号同步清理路由配置中的账号与提供商引用。
5. 修复：同步上游的数据库连接锁重入拦截、挂起与冷却分别落库，避免同线程重入死锁与账号状态只记一项；模型 Key 鉴权改阻塞加锁并在失败态从库自愈，高并发下不再随机 401。
6. 修复：ZCode 每日赠送套餐活动已下架，签到清单、签到时刻与插件申报同步移除，仅保留活动福利入口。
7. 修复：Trae 托管登录回调接受官方子域与 32 KiB 参数、容忍空字段与等值重复键；小浣熊账号清理 IAM 令牌与重复的无效刷新令牌；短信登录失败时推进重试时刻并补充日志。
8. 修复：网页端入口页与 Service Worker 不再缓存旧版本，子资源保留 ETag 304 并在链接上追加版本指纹。

## 优化

1. 优化：ZCode 客户端版本号在签到触发时按官网更新日志探测并对齐最新版本；模型路由改为自动参与，新添加账号带来的提供商无需手动加入。
2. 优化：请求详情弹窗加宽到 1120px，尝试明细表固定列宽与悬停全文；弹窗打开期间暂停页面级后台刷新，读库接口移入阻塞线程池。
3. 优化：同步上游的 WorkBuddy 正文上限 14 MiB 与资源正文通道、CatPaw 与 WorkBuddy 取消固定消息条数限制、凭证维护动态提前量、余额窗口排序。
4. 优化：签到清单按插件申报的每日签到能力过滤；签到卡与结果提示显示本次领取数量（WorkBuddy、CodeArts）；百度搭子「当月已签」按本月清单去重统计。
5. 优化：日志查询、统计、导出移入阻塞线程池；筛选候选清单新增内存缓存（短窗直读、活跃流量 5 分钟重算）；模型元数据启动预热；签到记录补 `(ts, row_id)` 复合索引。
6. 优化：网页工具调用支持调用块前后的正文与多块累积，前置说明不再被丢弃。
7. 优化：选路队列把「可用但并发已满」的候选排在队尾排队等槽位，面板显示「并发已满」而非不可用。
8. 优化：插件侧吸收上游签到与登录修复，包括 AStudio 零奖励套餐、Qoder 免费版不适用、OfficeAce 空奖励账本、Loomy 脱敏手机号、AutoClaw 错误详情与 Trae 续期时长字段。
