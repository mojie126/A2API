# Agent2API 3.5.0-beta.1 资产草稿（fork）

基于官方 3.5.0-beta.1（`aba58858`），协议库对齐 `v3.5.0-beta.1`；以下为 fork 增量改动，草稿正文由此文件自动生成，同版本的多次构建在本文件整合或追加。

## 核心更新

1. 新增：客户端识别供应商归属规则与默认归属客户端，请求日志按路由供应商改写最终归属，识别规则弹窗、归属显示与在途即时归属配套。
2. 新增：models.dev 模型身份绑定与代理选择，能力值按用户覆盖、提供商目录声明、models.dev 补齐的优先级合成，目录更新任务支持代理选择。
3. 新增：脚本插件 Bun 运行时一键清理，报错条与诊断弹窗提供入口，清理期间展示进度。
4. 新增：整库备份「包含日志与调试报文」开关跨会话记忆。
5. 新增：插件目录错误详情弹窗，展示官方名单、逐仓库失败与无法解析清单的具体原因和重试时间。
6. 优化：云同步 WebDAV 整次操作复用连接池，建连约 7 次降为 1 次，连接类失败自动重试一次。
7. 优化：弹窗遮罩取消入场动画，高负载下不再逐帧重算模糊掉帧。
8. 优化：独立路由表单布局，策略独占一行，会话粘滞与参与方式同行。
9. 优化：ZCode 定时领取验证支持浏览器后台标签页。
10. 优化：自动维护保留策略配置化，签到中心签到记录自动刷新。
11. 修复：图片兼容参与校验与保存校验对齐同一判据，别名启用、原始 id 关闭的视觉目标不再 403。
12. 修复：图片兼容视觉调用改用目标模型的账号池与路由 profile，移除请求路由参与门。
13. 修复：请求日志来源客户端显示与在途即时归属，归属改写带悬停与详情标记。
14. 修复：维护设置保留策略保存键名与后端对齐，保存即落库并立即清理。
15. 修复：路由页特殊请求路由的模型下拉随模型映射与获取模型刷新。
16. 修复：特殊请求路由的压缩上下文、图片兼容与标题生成规则新增、修改、删除后立即落库，失败时保留弹窗与错误提示。
17. 修复：标题生成规则保存后仍返回旧配置与旧修订号、页面刷新回退并反复报修订号冲突的问题。
18. 修复：图片兼容删除最后一条规则后又被旧版投影恢复的问题。
19. 修复：插件目录无法解析的清单不再反复报错，并入忽略生命周期，作者修复后自动恢复。
20. 修复：开放拉取请求复核中的维护保存与清理错误、路由回放别名匹配、空供应商归属、特殊请求手动重读竞态、图片兼容跨网关缓存、插件运行时清理等待、签到草稿保留与 models.dev 身份兜底。

## 其他更新

1. 新增：组件库新增 SearchSelect 单选搜索下拉与选项测宽工具。
2. 优化：图片兼容的「图片能力未知时」改为逐规则设置，可选择沿用全局设置、先发送原图后补救或直接按当前方式兼容。
3. 优化：请求日志列出图片兼容的实际判定结果，并显示模型已支持图片或能力未知而先发送原图的未应用原因。
