# Agent2API 3.5.0-beta.1 资产草稿（fork）

基于官方 3.5.0-beta.1（`aba58858`），协议库对齐 `v3.5.0-beta.1`；以下为 fork 增量改动，草稿正文由此文件自动生成，同版本的多次构建在本文件整合或追加。

## 新增

- 客户端识别供应商归属规则与默认归属客户端：请求日志按路由供应商改写最终归属，识别规则弹窗、归属显示与在途即时归属配套
- models.dev 模型身份绑定与代理选择：能力值按用户覆盖、提供商目录声明、models.dev 补齐的优先级合成，目录更新任务支持代理选择
- 脚本插件 Bun 运行时一键清理：报错条与诊断弹窗提供入口，清理期间展示进度
- 组件库新增 SearchSelect 单选搜索下拉与选项测宽工具
- 整库备份「包含日志与调试报文」开关跨会话记忆
- 插件目录错误详情弹窗：横幅保持一句话，弹窗展示官方名单、逐仓库失败与无法解析清单的具体原因和重试时间

## 修复

- 云同步 WebDAV 首次上传偶发「Network is unreachable」：整次操作复用连接池（建连约 7 次降为 1 次），连接类失败自动重试一次
- 图片兼容参与校验与保存校验对齐同一判据（`provider_serves_model`），别名启用、原始 id 关闭的视觉目标不再 403
- 图片兼容视觉调用改用目标模型的账号池与路由 profile，移除请求路由参与门
- 请求日志来源客户端显示与在途即时归属修复，归属改写带悬停与详情标记
- 维护设置保留策略保存键名与后端对齐，保存即落库并立即清理
- 桌面壳二进制名对齐打包名，lib crate-type 收敛 rlib（windows-gnu 本地构建修复）
- 画布整组拖到第一位时落点横条被裁剪的修复
- 路由页特殊请求路由的模型下拉随模型映射与获取模型刷新
- 插件目录无法解析的清单不再反复报错，并入忽略生命周期，作者修复后自动恢复
