# Agent2API 3.5.0-beta.1 资产草稿（fork）

## 核心更新

1. 新增：客户端识别供应商归属规则与默认归属客户端，请求日志按路由供应商改写最终归属，识别规则弹窗、归属显示与在途即时归属配套。
2. 新增：models.dev 模型身份绑定与代理选择，能力值按用户覆盖、提供商目录声明、models.dev 补齐的优先级合成，目录更新任务支持代理选择。
3. 新增：脚本插件 Bun 运行时一键清理，报错条与诊断弹窗提供入口，清理期间展示进度。
4. 新增：整库备份「包含日志与调试报文」开关跨会话记忆。
5. 新增：插件目录错误详情弹窗，展示官方名单、逐仓库失败与无法解析清单的具体原因和重试时间。
6. 新增：商汤日日新支持手机号验证码登录与官网滑块验证，保存 OAuth refresh token 并自动续期，添加账号与账号设置中的余额查询统一使用该登录方式。
7. 新增：调试模式支持精简、标准、完整三档采集内存预算，流式正文按头尾截断，调试数据采用有界异步批量写入。
8. 新增：果办支持只读模拟官方客户端状态，读取订阅、奖励、试用资源与续费状态并只返回白名单字段。
9. 优化：云同步 WebDAV 整次操作复用连接池，建连约 7 次降为 1 次，连接类失败自动重试一次。
10. 优化：弹窗遮罩取消入场动画，高负载下不再逐帧重算模糊掉帧。

12. 优化：ZCode 定时领取验证支持浏览器后台标签页。
