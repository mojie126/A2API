### 本轮 fork 自有修复与优化

- 弹窗活跃判定改为以真实打开状态为准：`isModalActive()` 直接查询 `dialog-content` / `sheet-content` / `alert-dialog-content` 的 `data-open` 属性，不再只看挂载计数。此前计数在页面生命周期内可能停在正数（弹窗组件常驻、计数与真实开关脱节），导致所有面板的实时刷新与轮询被永久按住——账号页连接数不出现、路由在途不流动、请求日志不更新，表现为「在途数据静止」。同时 `sync` 增加 `documentElement` 就绪判断，计数与真实状态不一致时自动归零。
- 请求日志轻量列表与按需详情：`RequestQuery` 新增 `view=list`，列表查询跳过重试链、敏感词与完整选路快照，只返回落屏列与摘要标记（识图信息单独取小对象），详情走新增的 `/api/stats/requests/detail`，前端列表带 `view=list`、弹窗打开时按 `rowId` 或 `id` 补齐。
- 请求日志事件驱动刷新：`panel_events` 新增 `requests` 主题与 `?scope=requests` 事件流，请求写入、在途回写、收尾、清理与维护裁剪后主动通知；前端新增 `page-live-refresh`，请求页改为事件驱动加断线兜底，空闲时不再固定 3 秒轮询，弹窗与悬停面板期间暂停刷新的本地约束保持不变。
- 脚本插件更新状态即时写入：安装 / 更新成功后由 `updates::record_installed` 直接写入该条目状态，卸载时 `remove_entry` 清理，替代整轮强制重算；刷新期间检测本地登记变化，变了就放弃旧快照，避免覆盖即时结果。
- 会话粘滞失败解绑：`StickySessions::forget` 按会话键、模型、候选与世代精确解绑，失败处理入口统一解绑后再走冷却与换号，固定指定账号的测试请求不改动正常粘性。
- 错误策略默认值与规则迁移：换账号默认值由 5 提到 32、上限放开到 100 并与 `MAX_ROUTE_ATTEMPTS` 对齐；全局规则升级为 v2（请求有误、内容拒绝、能力不支持与其他错误改为跳过提供商或换号并把优先级调到最低），读取配置时把逐字段等于 v1 默认值的规则迁移到 v2，用户改过的规则保持原样；新增 `CooldownMode::Deprioritize` 的账号级 / 模型级 / 提供商级降权窗口与连续失败延长，成功转发一次即解除。
- Codex 订阅图片通道：新增 `images.rs`，`gpt-image-2` 固定注入模型目录并标注图片能力，`/v1/images/generations` 与 `/v1/images/edits` 走 `ChatRequestPlan::images`，图片冷却只约束自身模型不与文字对话连坐。
- 请求详情弹窗加宽到 1120px，尝试明细表固定列宽与悬停全文，「上游身份」并入提示列；弹窗期间暂停页面级后台轮询与在途列表落屏，原文、调试报文与筛选候选三条读库接口移入阻塞线程池。
- 签到卡显示领取数量（网关把 `credit` 并入 `msg`；WorkBuddy 补读 `daily_credit`、CodeArts 汇总本次新到账积分）；百度搭子「当月已签」按本月日期清单去重统计；账号页连接数在详情未加载时仍显示。
- 修复网页端静态资源指纹改写重复输出剩余 HTML 的缺陷：此前网页端脚本被多次加载，刷新控件重复、页面卡顿，账号页在途连接数因多份 store 互相覆盖而不刷新；桌面端走内嵌资源不受影响。
