### 本轮 fork 自有修复与优化

- Codex 订阅图片通道：新增 `images.rs`，`gpt-image-2` 固定注入模型目录并标注图片能力，`/v1/images/generations` 与 `/v1/images/edits` 走 `ChatRequestPlan::images`，图片冷却只约束自身模型不与文字对话连坐。
- 请求详情弹窗加宽到 1120px，尝试明细表固定列宽与悬停全文，「上游身份」并入提示列；弹窗期间暂停页面级后台轮询与在途列表落屏，原文、调试报文与筛选候选三条读库接口移入阻塞线程池。
- 签到卡显示领取数量（网关把 `credit` 并入 `msg`；WorkBuddy 补读 `daily_credit`、CodeArts 汇总本次新到账积分）；百度搭子「当月已签」按本月日期清单去重统计；账号页连接数在详情未加载时仍显示。

## 四、准备做

1. 请求日志 `view=list` 轻量列表与详情接口：需前后端一并改，作为单独一项评估。
2. 第三优先口径整块迁移：换号默认值 + 错误规则 v1→v2 + 粘滞失败解绑，三项互相牵连。
3. 功能级单独立项：模型计价、面板 OAuth、通知渠道（云同步 S3 本地已有，不在此列）。
4. 科搭短信登录：插件先声明 `login.sms.*` 与 alicom4 → 网关接协议 → 桌面与手机端表单。
5. 插件侧 AutoClaw 活动按项领取：先补 `claims` 接口面与账本，再与网关联动。
6. 真机验收欠账：CodeArts 内置浏览器登录、WorkBuddy 14 MiB 长会话、CatPaw 长对话、余额窗口排序、签到领取数量、百度搭子当月天数、连接数列、Codex `gpt-image-2` 生成与参考图编辑。

## 五、本地改动保全清单（同步上游时逐条核对）

- 出口与路由：ZCode WARP 出口池与直连优先、登录与控制面继承账号出口、路由组内并发、模型路由自动纳入新提供商、删除账号清理路由引用。
- 上游请求：识图原图直转、客户端归属与上游身份拆分、思考档位覆盖、请求日志协议列、容量准入本地分支、Codex 订阅 `gpt-image-2` 图片生成与参考图编辑（模型目录固定注入、图片冷却与文字独立）。
- 插件宿主：原生插件安装与运行、安装入口先本机三元组再回退 WASM、插件更新源使用 fork 仓库、8 MiB 工作线程栈、脚本插件运行时清理。
- 数据与同步：schema v30/v31/v32 保留（现为 v34）、WebDAV 连接池与恢复本地优先、限额事件移出同步并修剪、无有效期账号刷新按无需续期处理。
- 界面：弹窗期间暂停后台刷新、悬停面板暂停刷新、特殊路由切换清空选中态、更新检查可彻底关闭、AutoClaw 国际版入口停用、提示条禁用滑动手势。
- 构建与发布：工作流仅手动触发、`fork-build.yml` 的 Windows 桌面与服务端为两个并行任务并启用并发取消（合并方案因依赖 feature 并集变化导致全量重编已回退）、发布说明只列 fork 增量。
